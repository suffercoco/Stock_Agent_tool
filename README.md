1. set env to upload file to nas

```Shell
# Mac command
echo "export STOCH_NAS_SHARE='stock'" >> ~/.zshrc
echo "export STOCH_NAS_USER=''" >> ~/.zshrc
echo "export STOCH_NAS_PASSWORD=''" >> ~/.zshrc
```

```Shell
# Windows command
setx STOCH_NAS_SHARE "stock" 
setx STOCH_NAS_USER "" 
setx STOCH_NAS_PASSWORD ''
```
